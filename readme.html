LOGIN FRONTEND GUIDE · 2026-08-14

ezREMS 로그인 페이지

Cloudflare의 운영 JSON과 로컬 fallback 자산을 결합한 독립 실행형 ezREMS 로그인 화면 안내서입니다.

기능구조콘텐츠자산배포점검오류 해결

주요 기능

마케팅 슬라이드자동 재생, 이전·다음, 일시정지와 다양한 시각 콘텐츠를 지원합니다.
긴급공지Cloudflare JSON의 사용 상태와 공지 내용을 로그인 영역에 표시합니다.
고객사 레퍼런스원격 로고 흐름과 성과 툴팁, 통계/보고서 링크를 제공합니다.
반응형 UI화면 폭에 자동 대응하는 레이아웃, 글꼴 선택과 접근성 보조 기능을 제공합니다.
구현 범위
현재 로그인과 상담 기능은 UI 목업입니다. 실제 인증 API 호출이나 개인정보 전송은 구현되어 있지 않습니다.

BI와 화면 아이콘은 로컬 images를 사용합니다. 고객사 로고는 현재 Cloudflare 콘텐츠 주소에서 불러오며, images/logos는 로컬 사본입니다.

페이지 시작 → JSON 3종을 독립적으로 요청 정상 응답 → 원격 JSON 표시 요청 또는 형식 오류 → login/js의 fallback 데이터 표시

요청에는 cache: no-store를 사용합니다. 마케팅 슬라이드와 고객사에서 enabled: false인 항목은 화면에서 제외됩니다.

배포 결과에 index.html, js/, images/가 모두 있어야 합니다. JSON은 콘텐츠 관리자 프로젝트에서 원격으로 읽으므로 로그인 프로젝트에 JSON 파일은 필요하지 않습니다.

배포 후 점검

  1. BI와 화면 아이콘 표시
  2. 마케팅 슬라이드 로드와 6초 자동 전환
  3. Cloudflare 고객사 로고와 성과 툴팁
  4. 긴급공지 상태와 문구
  5. 데스크톱·모바일 화면 폭의 반응형 표시
  6. 고객사 통계/보고서와 외부 링크
  7. 개발자 도구의 404, CORS 및 JSON 오류

오류 해결

증상확인 사항
고객사 로고 미표시JSON의 logoUrl, Cloudflare /content/images/logos/, 파일명 대소문자
고객사명만 표시로고 요청 실패로 텍스트 fallback이 작동한 상태
콘텐츠가 예전 내용원격 JSON 오류 및 로컬 fallback JS가 표시되는지 확인
CORS 오류콘텐츠 Pages 응답의 Access-Control-Allow-Origin 확인
BI·아이콘 미표시images/ 배포와 상대 경로 확인
JS 404js/가 배포 결과에 포함됐는지 확인
보고서 링크 오류콘텐츠 관리자 프로젝트의 client_report.html 확인

유지보수 원칙

  1. 운영 콘텐츠는 관리자 페이지의 JSON으로 관리합니다.
  2. JSON 변경 시 장애 대비용 login/js fallback도 갱신합니다.
  3. 고객사 로고는 콘텐츠 관리자 프로젝트의 content/images/logos에 배포합니다.
  4. 로그인 화면 전용 BI와 아이콘은 login/images에서 관리합니다.
  5. 실서비스 연결 시 목업 로그인 동작을 인증 API로 교체합니다.
분석 대상: login/index.html, login/js/*, login/images/*

마케팅 패널 배경 이미지

마케팅 패널 전체에 공통으로 사용할 JPG, PNG, WebP 배경 이미지를 선택할 수 있습니다(최대 5MB). 이미지는 content/images/backgrounds/에 저장되고 JSON에는 상대 경로만 기록됩니다.

backgroundImage, backgroundPosition, backgroundOverlay, backgroundAlt를 지원하며, 이미지가 없으면 기존 파란색 그라데이션 배경을 유지합니다. GitHub 저장 후 Cloudflare Dashboard에서 운영 배포를 수동 실행해야 합니다.

배경 테마 라이브러리

여러 공통 배경 테마를 등록·수정·삭제하고 재사용할 수 있습니다. themes 배열에 테마를 보관하고 activeThemeId로 현재 테마를 지정합니다. 기존 배열 및 단일 배경 형식도 계속 지원합니다.
