IP 위치정보

/api/location에서 접속 IP 기반의 대략적 위치를 조회합니다. GPS가 아니며 5초 타임아웃 또는 오류 시 “확인 불가”로 표시하되 로그인 사용은 유지합니다.

로그인 계정 연동

현재 폼 제출은 UI 목업입니다. 실제 서비스에서는 주석으로 표시된 formEl.onsubmit 영역을 내부 인증 API 호출로 교체해야 합니다. 비밀번호는 URL·로그·localStorage에 저장하지 않습니다.

파일과 배포

index.html은 화면과 API 연동, js/는 폴백·화면 설정, images/는 정적 자산입니다. login 폴더를 ZEONS/ezrems-login-renewal 저장소에 직접 업로드하면 GitHub Pages가 배포합니다. 콘텐츠 변경만으로는 로그인 재배포가 필요 없습니다.

점검

  1. 공개 API 3종 응답이 200인지 확인
  2. 관리자 저장 후 로그인 강력 새로고침
  3. 이미지 URL이 Cloudflare R2 공개 경로인지 확인
  4. 서비스 적용 전 인증 오류·세션·2차 인증 흐름 검증
